# Project Rules & Guidelines

## Shared Documentation Maintenance Rule
Always update `frontend/src/shared/shared.md` whenever:
1. Changes are made to the 2 primary entry-point files (`frontend/src/App.jsx` and `backend/app/main.py`).
2. Changes are made to any Uploader module files (`frontend/src/uploader/` or `backend/app/api/ADMIN_API/v1/uploader/`).
3. Changes are made to any Examiner module files (`frontend/src/examiner/` or `backend/app/api/ADMIN_API/v1/examiner/`).

*Note*: Do NOT update `frontend/src/shared/shared.md` for Admin module specific files (`frontend/src/admin/` or `backend/app/api/ADMIN_API/v1/admin/`).
